# Checklist: Pull Request

PR 제목·본문·머지 기준은 `docs/PULL_REQUESTS.md`를 따릅니다.

- [ ] PR 목적이 하나로 명확합니다.
- [ ] 리뷰 가능한 크기로 변경을 분리했습니다.
- [ ] 관련 없는 리팩터링, 포맷, 문구 변경을 제거했습니다.
- [ ] PR 본문이 `docs/PULL_REQUESTS.md`의 본문 템플릿 섹션(목적, 변경 사항, 영향 범위, 검증, 리스크 등)을 채웠습니다. 저장소에 `.github/PULL_REQUEST_TEMPLATE.md`가 있으면 그에 맞췄습니다.
- [ ] `docs/QUALITY_SCORE.md`의 최소 통과 기준을 확인했고, PR 템플릿에 Quality Score 체크가 있으면 반영했습니다.
- [ ] 앱 실행, 테스트, 린트, 타입체크, 빌드 또는 수동 검증 결과를 기록했습니다.
- [ ] 실행하지 못한 검증과 대체 확인 방법을 기록했습니다.
- [ ] 프로젝트에 필수 CI 또는 상태 체크가 있으면 통과했거나, 없거나 해당 없으면 N/A와 이유를 기록했습니다.
- [ ] 영향받는 화면, 컴포넌트, 상태, API를 적었습니다.
- [ ] 리스크와 주의할 영역을 적었습니다.
- [ ] UI 변경이 있으면 스크린샷 필요 여부를 확인했습니다.
- [ ] 토큰, API 키, 계정 정보 같은 민감정보가 포함되지 않았습니다.
- [ ] 관련 exec-plan, validation 기록, 추적 이슈가 있으면 PR 설명에 링크하거나 ID를 적었습니다.
- [ ] `docs/PULL_REQUESTS.md`의 **Merge Blockers**에 해당하지 않습니다.
